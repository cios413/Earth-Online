# 战斗人物贴图截图

战斗模式选中识别人物后，只登记该人物当前回合的截图状态。该人物被击败、2D 人物贴图首次完成姿态更新并实际显示时，立即请求截图，在这一帧渲染结束后保存为 PNG，包含贴图、AR 相机画面和游戏特效。

同一回合只截图一次，贴图持续跟随或重复刷新不会重拍。结算页在截图完成后展示本回合的图片和攻击统计，避免截到结算弹窗。截图失败会在图片区域显示提示；如果 PNG 写盘失败，仍尝试显示内存中的截图。

PNG 保存在 `Application.persistentDataPath/CombatSnapshots/`，文件名包含 UTC 时间、人物 ID 和回合 token。Unity Player Settings 中可以查看当前平台的 `persistentDataPath`。清理回合或关闭结算会释放内存图片；保存到磁盘的 PNG 保留。

贴图持续跟随人物或重复刷新不会重复截图；重新开始回合会等新回合的贴图重新显示后再拍。清空战斗会话、停止识别、人物丢失或应用切到后台时会取消正在等待或读取的截图，避免把旧回合的画面误存到新回合。暂停应用会取消待处理截图，不在应用恢复后补拍。

在编辑器运行 **Tools → Earth OL → Validate combat snapshots** 验证选人不截图、实际贴图首次显示时触发、重复刷新不重拍、PNG 文件、取消清理、结算等待，以及图片展示和内存回收。
