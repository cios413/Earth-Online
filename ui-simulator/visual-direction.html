三层 · 实景 / 锚定 / 界面

实景层去饱和 32% · 亮度 56% · 微模糊，不放任何文字
锚定层只锚人：识别后淡候选框，点选升级为 72% 实线墨框 + 距离标签
界面层100% 不透明墨底 + 骨白字 + 3px 硬描边 + 5px 硬阴影

三层靠「饱和度 + 不透明度 + 硬描边」分离，而不是靠颜色区分。任何一层都不与实景混色。

原则

  • 荧光做墨不做底，深色半调占八成以上。
  • 所有边缘同源：圆角也是像素阶梯，果冻按钮照样立体。
  • 长条贴纸是唯一信息容器，左端墨盖标类别，右侧深色承载内容。
  • 左对齐，只有数值右对齐；标题倾斜仅限破门与结算。
  • 只留一次入场墨迹；其余动效只回答用户的动作。

第二遍自检 · 改了什么

避开默认：「近黑底 + 单一荧光绿点缀」改成三色撞色且荧光只做笔触；同款圆角卡片套件改成长条贴纸 + 层级化阶梯角；满屏 ALL-CAPS 标签（PICK YOUR SIDEKICK / THROWABLE / TOP 3）全删。
解决冲突：「像素画风」与「大圆角果冻按钮」用阶梯化圆角统一；「高饱和」与「不刺眼」用面积控制与骨白替代纯白解决。
可验证：右侧三视图开关能直接拆开实景与界面，而不是只在文字里说分层。

组件规范 · 只有这六种零件

整套界面由六种零件拼成，不新增第七种。每种零件的圆角阶梯尺寸、描边厚度、阴影偏移都固定，移植进 Unity 时直接做成预制体。

果冻按钮 · 三态

阶梯化大圆角（--s:18px）、三段渐变高光、6px 硬阴影。按下时整体下沉 5px，阴影收成 1px，不用缩放弹跳。

长条贴纸 · 信息唯一容器

左侧墨盖标类别，右侧深色承载内容。成绩、预览、血量、状态全用它，不再出现第二种卡片。

像素阶梯角 · 边缘同源

按钮 18px / 面板 9px / 小卡 6px 三档，同一条阶梯曲线。右侧对比：平滑圆角不属于这套语言。

墨点喷溅 · 方块而非圆点

像素画风的落点：所有墨点都是方块点阵，不用模糊圆。静态只放两簇，投掷命中时才溅开一次。

半调网点 · 深色底纹

9px 主网点 + 18px 偏移的绿调次网点，透明度分别 8.5% 与 4.5%。只做质感，不形成可识别图案。

锚定框 · 贴在识别到的人身上

识别中只给淡荧光细框，点选确认后才升到 72% 实线墨框，略带 1° 手绘倾斜。半透明是「贴着」，不是「浮着」。

再加工对照 · v1 到 v2

v1（ui-simulator/index.html）已经把框架和流程跑通了，问题集中在「荧光面积」「图层分离」「装饰密度」和「信息层级」四件事上，改的是分配，不是推倒重来。

v1 · 已有的界面

  • 荧光大面积铺底：橙色发射按钮、模式 chip、榜单头部整块渐变，加上辉光与闪烁，盯久了刺眼。
  • 实景和虚拟同为深紫：网格地面 + 抽象人形 + 虚线锁定框，两层明度接近，分不清哪个是相机画面。
  • 装饰四散：准星、四角锁定角标、侧边 TOP3、常驻 chip、多道提示，同屏抢注意力。
  • 满屏英文大写：TAP THE SKULL / PICK YOUR SIDEKICK / THROWABLE / SCORE / COMBO / WIN!，中文反而成了附注。
  • 同款圆角卡片：chip、投掷卡、榜单、面板都是 12–18px 圆角盒 + 软阴影，层级靠字号硬撑。
  • 没有像素语言：骷髅是平滑曲线，墨点是圆形发光点，和「像素画风」没有共同形状。

v2 · 本提案

  • 荧光降到 10% 以内：只做墨盖、描边、数值与投掷命中瞬间；深色半调占八成，骨白替代纯白。
  • 三层硬分离：实景去饱和压暗微模糊，锚定层半透明，界面层 100% 不透明 + 硬描边 + 硬阴影，可用三视图拆开验证。
  • 装饰设上限：两簇静态像素墨点 + 一次命中溅开，删掉准星、四角标、侧边榜、辉光与闪烁。
  • 中文主导：「揉一下」「投出去」「本机成绩」，按钮说什么，反馈就说什么；英文只留 HP 一类真术语。
  • 长条贴纸统一容器：成绩、预览、血量、状态共用一种结构，圆角阶梯按层级分三档而非一刀切。
  • 像素语言贯穿：阶梯角、方块墨点、像素骷髅、crispEdges 描边，果冻按钮依旧圆润立体。

已拍板 · 交互逻辑

按你定的四条收紧了主分镜与结算分镜。下面每条都对应界面里一个可操作的状态，不是待办。

锚定：识别到人，点选锁定人

识别到人后先给淡荧光候选框，点一下才升级成实线墨框；锚定对象只限人，不做任意物体锚点。主分镜的「识别中／已锁定」开关可以直接验证两态。

对应工程：ObjectScanner 候选框 + PersonTracker 人检测 → 点选确认

主操作：选物品投掷，不选就形变

物品栏选中物品 → 按钮变「投出去」，点按投掷；不选任何物品 → 按钮是「揉一下」，点按触发软体形变。再点一次已选物品即取消选中。

对应工程：ThrowModeRuntime 投掷 / PokeDeform 软体形变

成绩：本机单局

结算只显示本机这一局的三条数据：得分、投中次数、形变次数。不接多人榜与校园榜，因此不需要昵称、名次和刷新状态。
